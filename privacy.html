Who uses this tool

Chef Wajan Studio Tools ("the tool") is a private desktop tool used only by the owner of the YouTube channel Chef Wajan (@ChefWajan) to manage that channel. It is not offered to the public and has no other users.

What data the tool accesses

Through Google OAuth 2.0 and YouTube API Services, with the channel owner's consent, the tool accesses only the owner's own YouTube channel:

  • channel and video information (titles, descriptions, tags, privacy status, schedule, playlists, captions, thumbnails) in order to upload and manage the channel's own videos;
  • the channel's own YouTube Analytics reports (for example views, watch time, audience retention, subscribers gained) in order to plan future videos.

The tool does not access other people's channels, comments, contacts, email, payment details or any other Google data.

How the data is used and stored

  • The OAuth token is stored only on the channel owner's own computer, in a private local file. It is never published, shared or sent to any server other than Google's.
  • Analytics numbers are saved as local files on the owner's computer for planning. They are not sold, shared, or used for advertising.
  • No data is transferred to third parties. No cookies or trackers are used by this website.

Retention and deletion

Local data is kept only as long as it is needed for running the channel and can be deleted at any time by the owner. Access can be revoked at any time at Google Account → Security → Third-party access; revoking it stops the tool from accessing the channel.

YouTube API Services

The tool uses YouTube API Services. Use of the tool is subject to the YouTube Terms of Service, and the Google Privacy Policy describes how Google handles data.

Changes

If this policy changes, the new version will be posted on this page with a new date.
